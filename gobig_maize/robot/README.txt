# BEGIN README.txt

robot - README.txt

./GObig_maize_descriptions.csv
	Aggregate file of all three categories of the GO terms found under 
	../GO_terms. This file contains information about the terms including GO ID, 
	ontology category, term description, and link. This file is the input for 		
	the Python notebook file described below.

./Getting_Subset_Query-Maize.ipynb
	A Python notebook file that properly formats the input into an output file 
	for the ROBOT tool.

./Subset_query_maize.txt
	The output file generated by Getting_Subset_Query-Maize.ipynb that contains 	
	the seed terms specified that need to be extracted using the ROBOT tool. The 
	file has been modified to include the relations as well.

./pre_gobig_maize.owl.gz
	The modified go.owl file after tagging the collected GO terms in Protégé 		
	with the gobig_maize subset label. This file is used as input to extract the 
	gobig_maize subset and create the new OWL file using the ROBOT tool.

************************************************************************************

For more information about the ROBOT tool:
https://github.com/ontodev/robot/tree/master
https://doi.org/10.1186/s12859-019-3002-3

For instructions on how to download ROBOT:
https://robot.obolibrary.org/

To generate the final gobig_maize.owl file, use the robot command "extract" 
(https://github.com/ontodev/robot/blob/master/docs/extract.md) with the 		
"subset" method as shown below.

From command-line run:
robot

robot extract --method subset --input pre_gobig_maize.owl --term-file Subset_query_maize.txt --output gobig_maize.owl
